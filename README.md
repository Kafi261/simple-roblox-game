# Hantu Malam - Horror Game Roblox
**Hantu Malam** (Night Ghost) adalah game horror Indonesia yang terinspirasi dari mitologi dan legenda lokal Indonesia.

## 🎮 Konsep Game
- **Genre:** Horror Survival
- **Tema:** Mistis Indonesia - Hantu, Penunggu, Sumur Tua
- **Gameplay:** Escape dari rumah berhantu sambil mengumpulkan item untuk melarikan diri
- **Setting:** Rumah tua di desa Indonesia pada malam hari

## 🕷️ Fitur Utama
- Hantu NPC yang mengejar pemain
- Sistem sanity/ketakutan
- Puzzle dan pencarian barang
- Efek suara horror
- Ending berbeda berdasarkan pencapaian pemain
- Dialog dalam Bahasa Indonesia

## 📁 Struktur Proyek
```
hantu-malam/
├── Models/               # Asset 3D
├── Scripts/             # Script Lua
│   ├── Player/
│   ├── Ghost/
│   ├── GameManager/
│   └── UI/
├── Assets/              # Sound & Musik
└── Maps/                # Level design
```

## 🚀 Cara Mulai
1. Buka di Roblox Studio
2. Insert script dari folder `Scripts/`
3. Konfigurasi spawn point dan ghost behavior
4. Test gameplay

## 👻 Legenda Indonesia
- **Hantu Penunggu:** Hantu rumah yang menolak orang pergi
- **Sumur Tua:** Sumber kutukan
- **Malam Gelap:** Waktu ketika hantu paling kuat
